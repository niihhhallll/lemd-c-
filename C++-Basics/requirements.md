# Project Requirements

## Overview

This project is designed to demonstrate fundamental C++ programming concepts while following a clear and organized project structure.

## Requirements

The project must satisfy all of the following requirements:

- **Multiple Functions:** The project must contain multiple functions.
- **Return Value:** At least one function must return a value.
- **Void Function:** At least one function must be a `void` function.
- **Parameters and Arguments:** At least one function must accept parameters and be called using arguments.
- **Multiple Source Files:** The project must contain more than two source code files.
- **Namespace:** The project must use a namespace.
- **Preprocessor Statement:** The project must include at least one preprocessor statement, such as `#include`.

## Project Task

Develop a complete C++ project that satisfies all the requirements listed above.

The project should:

1. Demonstrate the use of multiple functions.
2. Include both value-returning and `void` functions.
3. Include a function that accepts parameters and is called with appropriate arguments.
4. Be organized across more than two source code files.
5. Use a namespace to organize the code.
6. Include at least one preprocessor statement, such as `#include`.
7. Follow proper code structure, organization, and readability practices.
